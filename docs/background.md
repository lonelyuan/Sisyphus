# 一、我和拖延症的战争

> 我希望这是一篇爆款文案，具备抓人眼球的标题和开头，妙趣横生的展开和灵魂升华的结尾。但我写不出，于是尝试了许多次。
> 

笔者和拖延症的故事发源于偶然接触到的一本畅销书：《拖延心理学》。书中首先描述了经典的“拖延循环”：

- 任务开始：信心满满，估计时间还很充裕，先摸一会。
- 任务中期：忽然发现时间不太够了，但努努力还有希望。或者完成了一小块任务，然后又可以心安理得的继续摸鱼。
- 任务后期：DDL临近，忽然发现拼尽全力也难以完成了，于是开始考虑如何放弃止损。
- 任务结束：DDL前的熬夜奋斗最多也只能换来低质量交付。于是下定决心下次一定不要拖延，但现在我需要休息。

这本书给高中时期的笔者带来了小小的认知震撼，“这简直就是我！”。这种醍醐灌顶的感觉让笔者坚信，阻止本人成功的首要因素就是拖延症。于是笔者进行了最详细的阅读笔记，并紧跟书中给出的实操方法进行实践。至于这些实践的结果，笔者相信在当时或许有些作用，但随着高考这个最大最凶的DDL的临近，仅是完成学校的课业就已经让笔者拼尽全力了，至于什么番茄钟、打卡表自然是高高挂起。

但进入大学后，相对自由散漫的生活又让我陷入了拖延症的焦虑中。由于笔者具有丰富的和拖延症战斗的经验，笔者在任务中期往往还有另一个环节，那就是意识到自己的拖延症又犯了，于是开始转过身筹划和拖延症的再一次战斗。作为计算机专业的学子，笔者不止一次设想过用计算机的方式，通过代码和AI模型来帮助我战胜拖延症，这个项目就是**西西弗斯计划（**Project Sysiphus）。

显然，同样由于拖延症的存在，笔者从未完成过这些想法的开发落实。原来这种行为本身就是拖延症的体现而非改善，俗话说磨刀不误砍柴工，但人在快饿死的时候确实不应该先磨刀。不管怎样，笔者顺利完成了本科和研究生学业。其间，疫情席卷全球又消失的仿佛从未发生，ChatGPT横空出世却只带来新的焦虑。在快速变化的世界和更大的人生迷茫面前，拖延症早已无关紧要。每个人都自顾不暇，这便是笔者对拖延症的首次祛魅，它不过是彼时互联网的时尚单品，足以让尚未开智的笔者狂热罢了。

但笔者总是会再一次捡起拖延症的话题。我早已知晓，并不是解决了拖延症的问题之后就一定能获得世俗意义上的成功，个人的努力程度不过是成功的诸多因素中最不起眼的一个。可回顾这短暂的人生，依旧有许多遗憾让人感慨：“如果我早做打算就好了”，“如果我抓住机会就好了”。于是会怀疑，在这一场又一场西西弗斯式的挣扎中，究竟能否积累到足以引发质变的量变？我和拖延症的战争，这绝不仅仅是一次心理学研究，而是有一个有关如何实现自我进化、如何成为更优秀的自己的伟大梦想。这个梦想在问：人究竟能否在牢固舒适的旧习惯中、在繁重麻木的生活之外，通过自己的意志改变自己的命运？

有关上述问题的实践探索和最终证明，就是西西弗斯计划的目标。

# 二、西西弗斯计划：推动习惯的巨石

笔者曾三次起草西西弗斯项目的架构，曾设想一个能够全天候观察你、用AI模型智能预测你并用大模型和你亲切对话的个人助手APP。但笔者显然低估了软件工程的复杂程度，每次都只能写一个最小demo，然后是三分钟热度的消失，下一次从头再来。LLM智能体的飞速发展改变了一切，完成这个项目的门槛越来越低，甚至笔者要怀疑这个idea或许早就有人做了。但是截止到2026年，市场上并不存在在个人助手领域比本项目的idea更优秀的产品。笔者的市场调研结论如下：

> 
> 
> 
> ### 调研计划
> 
> 1. 拖延症的生理原理。包括作者、来源（学术期刊，设计心理学生理学神经学等领域）、关键观点，主流模型等
> 2. 同类产品调研。包括日程类软件的基本设计，效率促进的软件和课程等材料。是否有产品/文章提出了与本项目契合的想法，或已经有了现有实现。
1. 效率类软件：如滴答清单、番茄时钟等。其宣称能够帮助用户提高效率，但本质都是记账软件，也存在一些使用游戏化机制和奖惩机制的特化产品，但他们都是在隔靴搔痒，都无法回答一个核心阻碍：如何让一个拖延症患者消耗巨大的学习成本来习惯于使用你的软件呢。这本身又会陷入磨刀误了砍柴功的悖论。
2. 环境控制类软件：如不做手机控。在权限上确实拉满了，能够保证你不玩手机。但是设置合适的策略还是学习成本太高。并且这类对抗性质的app总会激发人的叛逆心理。
3. 培训机构和陪伴监督服务：如暂停实验室等。这位更是重量级，心理咨询师没活了拓展业务来了。我的评价是太传统了不如维新派。
4. 推荐算法：短视频、信息流是移动互联网时代的关键创新，但大厂只会将其用于营销卖货、促进短视频上瘾、洗脑用户心智向反智主义消费主义靠拢、构造信息茧房甚至是操纵舆论。但凭什么这种能影响人心的大杀器只能为资本所用呢？
5.  LLM智能体：现如今AI更加接近贾维斯的形态，自然语言接口才是真正0学习成本的交互方式。但是现如今LLM从架构上并不适合实时监控你的一举一动，系统还是需要一套确定性的算法、状态机等模型来驱动LLM进行交互。
6. 可穿戴设备：如智能手表、智能眼镜等。物联网设备等普及给用户行为建模提供了广阔的实现空间。
    1. 最新的创业产品Looki：全天候相机记录+LLM识图总结。更加接近本项目的产品形态，但只让LLM来做备忘录还是太没创意了。

综上，西西弗斯计划的系统核心架构逐渐明朗：

1. 行为采集端：包括手机、电脑、穿戴设备等个人终端，忠实记录用户的一举一动上传至数据库；
    - 数据安全：作为网安从业人员，如此详细且机密的个人数据当然值得警惕。为此本项目必须支持开源且本地部署。
2. 习惯模型：利用行为学、心理学等理论，指导启发式规则、深度学习等模型，建模用户的习惯，根据个人数据训练模型并输出实时干预决策。
3. 交互智能体：利用LLM的对话能力，给用户发出主动的、富有情感的提醒，并利用智能体完成对环境的干预操作。

另外，笔者希望本项目不仅解决拖延症问题，而是AI时代下最懂你能帮你的个人助手。笔者设计了以下功能模块：

1. 西西弗斯计划（狭义）：上述针对拖延症的观察机制。但这套闭环系统也可以拓展到其他行为习惯的干预中。
2. 原声笔记：0压记录，无学习成本的一站式笔记+效率软件。只需告诉它你的任意想法，智能体帮你设立日程，任务，计划，整理灵感、知识、见解。
3. 第二大脑：和用户共享视野、能够持续迭代的LLM知识库。将繁琐的知识整理交给AI，你只需要丢给他原始材料或者直接让他deep research，智能体将持续更新知识图谱，保持剪枝和验证，始终输出用户高度可读的内容。

可见，本项目横跨多类终端，三大模块相互交流。

> 例如，我想学游泳？想法→（原声笔记）→意图→计划→提醒→（西西弗斯）→习惯培养→（第二大脑）→游泳知识文档。

## 三、后智能体时代的软件工程

这一发vibe，是笔者8年CS学子的软工功力。技术栈：

- APP开发：使用跨端开发框架Tauri，能够共享端侧无关的代码。
    - 行为检测API：浏览器历史记录，应用启动记录，手机手势动作，屏幕截图……
    - 反馈API：弹窗（调用智能体）、干预用户环境（关闭进程）……
- 数据结构：学习SOC的设计思路，定义统一数据结构，兼容行为记录和用户输入。在初期每个端侧各自实现数据库和状态机维护，后期也能够方便的进行跨端联合建模。
- 习惯引擎：前期启发式规则引擎，后期引入模型微调。
- 智能体基座。APP提端将作为智能体的工具完全解耦。初期可仅编写skill来使用Codex等优秀智能体基座，方便的使用定时任务等功能，后期也可切换到自研智能体底座。
    - skill：事件协议，API调用方法，用户交互技巧，个性化长记忆……
- 存储结构：知识图谱采用双链笔记或者图数据库，兼容OB等外部软件。
