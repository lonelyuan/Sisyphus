三层结构

接入层（设备/传感：电脑·手机·未来智能眼镜/可穿戴）→ 功能层（三大模块）→ 生态层（Notion/Obsidian 等外部系统）。用户在回路：被动收集 → 系统 → 主动提醒 / 主动展示回到用户。

无压记录 = 总入口

零压力 InputBox → 意图识别 Agent（Codex / Pi）做功能路由：习惯培养→西西弗斯、知识工程→第二大脑；人生看板只把用户维护的 上下文 回喂智能体。= capture + propose_intents。

西西弗斯 = 感知闭环

行为采集 → 行为日志 → 习惯引擎（规则匹配，RL 后续）→ 情感干预 Agent（心理语料库）→ 提醒干预。被动收集、本地实时，不经 InputBox。

开发计划（相位）

实线=现阶段：复用 Codex/Notion/Obsidian + 规则引擎。虚线=后续自建 / 长期克制：智能眼镜·可穿戴 IoT、RL/无监督、跨端联合建模、时间线/技能树、知识图谱、拓展路由模块、Pi 基座。替换的只是交互前端，Core+MCP 契约不变。
